# 界面优化说明（v6）

> 范围：全局外壳、页面骨架、表单/按钮/卡片/列表/弹窗/抽屉/阅读器工具条，以及响应式。
> 原则：**只改样式与视觉表达，不改任何交互逻辑、数据结构与文案**；阅读器的三种主题（羊皮纸/纯白/深色）保持原样。
> 预览：`docs/ui-preview.html`（用同一份 `styles.css` 渲染的静态样张）。

---

## 1. 设计令牌：先统一，再谈美化

之前颜色是零散硬编码的（`#c8cdd8`、`#d9dcff`、`#f0cdd5`…），同一个"浅边框"在不同组件里有四种值。现在全部收敛到 `:root`：

| 类别 | 令牌 | 值 / 说明 |
|---|---|---|
| 色板 | `--bg` `--surface` `--surface-2` `--surface-3` | `#f6f7f9` / `#fff` / `#fafbfc` / `#f1f3f7`，三级表面区分"页面底—卡片—卡内分组" |
| 边框 | `--border` `--border-strong` | `#e4e7ee` / `#d3d8e2`（hover 才加深，不再随手写色值） |
| 文字 | `--text` `--text-2` `--muted` | 主/次/弱三级，正文对比度 ≥ 7:1 |
| 主色 | `--primary` `--primary-hover` `--primary-soft` `--primary-line` | 统一靛蓝，软色用于选中态与焦点环 |
| 语义 | `--danger/-soft` `--ok/-soft` `--warn/-soft` | 之前每个组件各写一份，现在共用 |
| 间距 | `--sp-1…6`（4/8/12/16/24/32） | 所有 padding/gap 从这里取 |
| 圆角 | `--r-sm 7` `--r-md 10` `--r-lg 14` `--r-pill` | 按"控件 < 卡片 < 弹窗"分级 |
| 字号 | `--fs-xs 11` `--fs-sm 12` `--fs-base 14` `--fs-lg 16` `--fs-xl 22` | 之前 11/12/13/13.5/14/15 混用 |
| 阴影 | `--shadow-1/2/3` | 静态卡片用 1、悬停用 2、浮层用 3 |
| 焦点 | `--ring` `--ring-danger` | 统一 3px 半透明环，键盘可见 |
| 动效 | `--dur 140ms` | 所有过渡同一节奏，并支持 `prefers-reduced-motion` |

**改前**：颜色/间距/圆角各处手写，同一个"次要文字"在不同页面是 `#8a93a2` 和 `#5b6472` 混用。
**改后**：任何新组件只需要引用令牌，视觉天然一致；改主题色只改一行。

## 2. 逐页面 / 组件：改动前 → 改动后

### 2.1 应用外壳（侧栏）

| 维度 | 改前 | 改后 |
|---|---|---|
| 品牌区 | 纯文字标题 + 一行小字说明，与导航同级 | 左侧加 17px 渐变色块作为应用标记，标题缩进对齐，小字降为 11px 弱化 |
| 导航项 | 34px 高、`hover` 只换底色，激活态仅浅紫底 | 36px 高、统一 8px 圆角；**激活项左侧 3px 竖条** + 浅紫底 + 600 字重；hover 用 `--surface-3`（更轻） |
| 禁用项 | 只有 `cursor:not-allowed` | 透明度 38%，明确"不可点" |
| 底部信息 | 与导航贴在一起 | 加 1px 分隔线，与导航分区 |

> 价值：左侧栏是常驻区域，一条竖条就能让"我在哪一页"在余光里成立。

### 2.2 页面骨架（世界观 / 剧本 / 设定集 / 设置 / 粘贴工作区）

| 维度 | 改前 | 改后 |
|---|---|---|
| 页面内边距 | 固定 `26px 30px 60px` | `--sp-6` 起的响应式内边距（32→24→18→16） |
| 标题 | 固定 22px，副标题贴得很近 | `clamp(20px, 2vw, 24px)`，副标题 12px / 行高 1.6 / 距标题 5px |
| 头部对齐 | `align-items:center`（有副标题时标题会被拉偏） | `flex-start`，多行副标题不再挤压按钮 |
| 内容宽度 | 1240px | 1180px（配合正文行宽，卡片不至于拉得过长） |
| 卡片 | 圆角 12、`--shadow` 双层阴影、`card+card` 间距 16 | 圆角 14、静态只用 `--shadow-1`（更安静）、间距 14 |
| 卡片标题 | 单行文字 | flex 排列，徽标/计数与标题基线对齐、可换行 |

### 2.3 按钮（全局）

| 维度 | 改前 | 改后 |
|---|---|---|
| 尺寸 | padding 决定高度，主按钮 33px、抽屉里 27px、工具栏 26px，参差 | 统一 `height:32px`（`btn-sm` 27px），同一行按钮必然同高 |
| 主按钮 hover | `#4239d0` 硬编码 | `--primary-hover`，与主色同源 |
| 危险按钮 | 白底红字，hover 变色不统一 | 白底红字 + 红边，hover 用 `--danger-soft` |
| 按压反馈 | 无 | `:active` 下移 1px（60ms），有"按到了"的确认感 |
| 焦点 | 无可见指示 | `:focus-visible` 统一焦点环 |
| 禁用 | 仅 `opacity .5` | `opacity .45` + 保持 `not-allowed` |

### 2.4 表单（连接配置 / 策略面板 / 新建剧本 / 导出）

| 维度 | 改前 | 改后 |
|---|---|---|
| 控件高度 | `padding:8px 11px`，随字号浮动 | 统一 `height:34px`（textarea 例外），一行多个控件对齐 |
| hover | 无 | 边框加深到 `--border-strong`，先于聚焦给出"可操作"信号 |
| 聚焦 | 边框变紫 + 3px 软色环 | 同机制，环色改从 `--ring` 取，与按钮一致 |
| 占位符 | 默认浏览器灰，偏深 | `#aab2c0`，与 `--muted` 拉开层级 |
| 标签/提示 | 12px/11px，行高不定 | 12px/600 标签 + 11px 行高 1.55 的提示，形成三级层次 |
| 复选框 | 浏览器默认尺寸不一 | `accent-color: --primary`，15px 统一 |

### 2.5 标签页 / 列表 / 卡片墙（设定集）

| 维度 | 改前 | 改后 |
|---|---|---|
| 页级 tab | 8×14 padding，hover 无反馈 | 36px 高、上方圆角、hover 有底色，激活 600 字重 |
| 列表项 | hover 仅换边框 | 悬停边框加深 + `--shadow-1`，不位移（避免抖动） |
| 设定卡 | hover 只换边框色 | hover 上浮 1px + `--shadow-2`，明确"可点开" |
| 空态 | 26px 内边距、虚线框 | 28px/20px，字号 13px，视觉重量与卡片一致 |
| 徽标 | 11px、行高 1.7，高度不齐 | 统一行高与 999 圆角，与文字基线对齐 |

### 2.6 弹窗 / Toast

| 维度 | 改前 | 改后 |
|---|---|---|
| 背景遮罩 | 纯半透明 | 42% 深色 + `backdrop-filter: blur(2px)`，焦点更集中在弹窗 |
| 弹窗入场 | 直接出现 | 180ms 上移 8px + 轻微缩放，`--shadow-3` |
| Toast | 左下 3px 色条 | 左侧加 7px 圆点指示（成功=主色/失败=红），180ms 上滑入场 |
| 窄屏 Toast | 固定 420px 宽，可能溢出 | ≤900px 时左右各留 16px |

### 2.7 阅读页（保持主题，不动排版参数）

| 维度 | 改前 | 改后 |
|---|---|---|
| 工具条 | 9×20 padding，按钮高低不一 | 10×22，分段控件统一 28px 高 |
| 抽屉 | 固定 320px，始终占位挤压正文 | ≥1024px 仍是并排；**<1024px 改为右侧浮层**（380px，带阴影与滑入），正文不再被挤成窄条 |
| 选区 | 浏览器默认 | 半透明紫，和主色一致 |

> 阅读正文的字体、字号、行距、页宽、三种主题**完全没动**——那是用户自己调的。

## 3. 响应式：按"窗口变窄"的优先级收

| 断点 | 处理 |
|---|---|
| ≤1200px | 侧栏 236→208，页面内边距收一档 |
| ≤1024px | `.grid-2` / `.form-grid` / `.policy-grid` 变单列；设定集卡片列宽下降；阅读页抽屉改浮层 |
| ≤900px | 应用外壳由"左右"变"上下"：侧栏变顶部横条（可横向滚动），隐藏品牌副标题与底部信息；页面头部改纵向排列；Toast 全宽 |
| ≤640px | 标题 19px、卡片内边距 16；`.split` / `.lore-layout` 单列；卡片墙单列；阅读副标题隐藏、正文左右内边距再收 |

**改前**：全站没有任何媒体查询，窗口一窄侧栏不动、双列表格挤压、阅读抽屉把正文压到 300px 宽。
**改后**：先收间距、再收列数、最后换布局，任何宽度下都不出现横向滚动。

## 4. 交互反馈清单（新增，均不改变行为）

- 所有可点元素有 `hover` 与 `:active` 两态；按钮按下位移 1px。
- 键盘 `:focus-visible` 统一焦点环（此前 Tab 到按钮完全看不出焦点）。
- 导航激活态有竖条 + 底色 + 字重三重指示。
- 弹窗/抽屉/Toast 有入场动效，节奏统一 140–180ms。
- `prefers-reduced-motion: reduce` 时全部动效降到 0.01ms。
- 自定义滚动条（10px，悬停加深），长列表不再出现系统粗滚动条打断视觉。

---

## 5. 明确没变的东西

- 所有组件的 class 名、DOM 结构、文案、交互逻辑、IPC 调用**均未改动**；改动集中在一个 CSS 文件（令牌 + 追加的 v6 层）。
- 阅读器三种主题的 `--novel-*` 变量、字体栈、行距、页宽记忆全部保留。
- 深色模式仍只作用于阅读页；全站深色是另一件事（需要逐组件定义暗色令牌），未在本轮夹带。
- 无新增依赖、无网络请求、无数据迁移。

---

## 6. 取舍与后续

1. **为什么用"追加覆盖层"而不是重写**：467 行既有样式里有一半是阅读器与 CodeMirror 的细节，重写风险高、收益低。令牌替换 + 追加 v6 层能保证"旧规则仍在、冲突时新规则生效"，且 diff 可读。
2. **侧栏没有做图标**：加图标需要引入图标库或 SVG 资产，属于功能面扩张；目前用竖条 + 字重已能表达层级。
3. **下一步可选**：全站深色（定义 `:root[data-theme="dark"]` 一整套令牌 + 设置项）、密度切换（紧凑/舒适两档间距）、以及把 `.toast` 换成可堆叠的通知中心。
