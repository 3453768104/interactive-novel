# 不夜城 · 点灯人 — 演示用开局

> 原创设定，专为录屏演示写。**不含任何第三方作品内容**，可以放心发。
> 目标：3 分钟能建完，第一屏就有钩子，选项一眼看得出"有得选"。

---

## 一、建库步骤（约 2 分钟）

1. **世界观** → 新建，名字填 `不夜城`
2. 进「设定集」→ **导入 Markdown** → 选 `docs/demo-world/设定集.md`
   → 自动得到 **5 个分类 / 15 张卡**
3. 同一页 → **事件背景** → 粘贴 `事件背景.md` 全文（约 600 字，全量注入）
4. **剧本** → 新建，四个字段照下面粘
5. 进「阅读」→ 模式选 **网页粘贴**（不用装模型）或 **本地推理**

---

## 二、剧本四字段（直接复制）

**剧本名**

```
不夜城·点灯人
```

**主角名**

```
沈砚
```

**主角人设**（这一段每回合 100% 注入、不裁剪）

```
沈砚，十七岁，不夜城灯市口「柳记灯铺」的学徒。师父柳三更三月前失踪，铺子如今只剩他一个人撑着：白天修灯、代写灯名，晚上守着后屋米缸里那盏不该存在的无名铜灯。

他不点自家的命灯——铺子的灯是师父留下的，户名还是柳三更，规矩上他不能动。所以这三个月他其实一直在"半熄"的边缘：忘过两次事，一次忘了昨天收过谁的钱，一次忘了师父走那天有没有下雨。

右眼眼角有一点灯斑，七岁被灯火烧的。从此他在暗处能看见别人灯周围那层光：光厚的人是活得扎实的，光薄的人快熄了。他靠这个判断街坊还剩几天。

嘴硬，心不硬。说话短，爱答"嗯""不碍事""随你"。对灯曹的人客气得过分，客气到有点假。真正想做的事只有一件：弄清楚师父去哪了。其次是不让铺子熄灯。

他知道的：灯曹在收"余灯"；城南在接连熄户；师父破过第三条戒。
他不知道的：铜灯灯底的那个指印是谁的；岑九娘腕上那道疤为什么眼熟。
```

**开场情境**（只在前 3 回合注入）

```
雨下了七天。夜里三更过半，柳记灯铺的门板被雨泡得发胀。后屋米缸里那盏无名铜灯忽然自己亮了——没有火镰，没有灯引，焰是极淡的青色。

沈砚从铺板上坐起来，右眼那点灯斑隐隐发烫，暗处看得见的东西比平时多了几分：门外的雨里有三团光，两薄一厚，停着没动。

然后有人敲门。不轻不重，隔一会敲一下，很有耐心。
门外传来一句："柳记的，查灯。"
```

## 三、第一回合大概会给什么选项

模型通常会给出类似这几条（演示时点第 2 条最好，因为能立刻展示"暗场"）：

1. 开门，把灯罩擦亮，装作刚醒
2. 不应声，从窗纸破洞往外看一眼那三团光
3. 先把铜灯塞回米缸，再应门

> 想让演示更有戏：在「导演」抽屉的**本回合指令**里写一句
> `无论怎么选，本回合结尾让岑九娘本人出现在门外，且她认出了铜灯。`
> 这句话整段注入、不裁剪，用掉一次就清空——正好演示导演模式。

## 四、录制时值得给镜头的三个点

| 镜头 | 怎么演 | 对应卖点 |
|---|---|---|
| 导入设定集 | 点「导入 Markdown」→ 选文件 → 卡片墙刷出 5 个分类 15 张卡 | 设定集不是手打，是能导入的 |
| 置顶卡 | 把「灯的三等」点 ★ | 重要设定每回合都在，不靠运气 |
| 上下文抽屉 | 生成一回合后打开 → 预算表里「常驻设定卡」「设定集目录」「设定检索」三行都有数 | 注入了什么，能看见、能改 |

---

## 五、为什么这套适合演示

- **规则极简但自洽**：灯=命，油=记忆。观众三句话就能懂，模型也不会跑偏。
- **天然有"暗场"**：主角右眼只能看见"光"，看不见别人的心思——切全知视角时，岑九娘的真实动机一露，反差立刻成立。
- **天然有"状态"**：沈砚在"半熄"边缘、只剩两根半灯引、铜灯烧了七天没添油——这些都能直接落进状态卡的物品与持续状态字段。
- **天然有"检索"**：15 张卡里"无主灯""灯底指印""岑九娘腕疤"三条是伏笔，检索命中时观众能看出"它真的读了设定"。
