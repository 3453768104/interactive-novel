### 脚本（改文案就改这里，重跑即可）

| 文件 | 作用 |
|---|---|
| `make_covers.py` | 生成全部图片（封面 / 静帧 / 文字层 / 片尾 / 文字卡） |
| `make_srt.py` | 生成两份 SRT 字幕 |
| `render_clips.sh` | 渲染片头 / 片尾 mp4 |
| `make_shots.py` | 把真实界面截图裁成竖屏卡片层（要换截图就改这里的裁切框） |
| `render_teaser.sh` | 合成 15 秒预告片 |

```bash
python make_covers.py && python make_srt.py
python make_shots.py                        # 真实界面卡片层
sh render_clips.sh && sh render_teaser.sh   # 需要 ffmpeg 在 PATH
```

**真实截图怎么放进去的**：截图是 16:9 的宽屏窗口，整张塞进竖屏会小到看不清字。所以只裁「正文 + 三个选项」和「额度滑杆」这两块信息密度最高的区域，按 1000px 宽放进画面，卡片下方/上方各配一句字幕——手机上一眼能读清。

**换截图**：把新的界面截图覆盖成 `docs/promo/src-reader.png`（阅读页）或 `src-settings.png`（设置页）即可，裁切框在 `make_shots.py` 里。原始截图不入库（体积大、含个人数据），只提交生成脚本。

封面上的中文是 Pillow 用系统字体（宋体 + 雅黑）排的，不是 AI 画的——AI 生图写中文必然糊字。**改字只需改脚本里那几行字符串再跑一次**。

## 1. 竖屏 · 抖音（30 秒，9:16）

节奏原则：**前 3 秒必须让人知道"这跟别的 AI 写作工具不一样"**，全程字幕，不留空白。

| # | 时间 | 画面（你录什么） | 屏幕字幕（每行 ≤ 12 字） |
|---|---|---|---|
| 1 | 0.0–3.0 | `still-douyin` 静帧，缓慢推近到 108%，主标题已印在图上 | （无字幕，让封面字说话） |
| 2 | 3.0–5.5 | 阅读页，正文缓缓上滚（羊皮纸主题、沉浸模式） | 它写得像小说\n而且记得上一章 |
| 3 | 5.5–9.5 | 屏幕下方三个选项浮出 → 鼠标点亮第二个 → 「正在写…」→ 新正文流式出现（**1.5× 加速**） | 但下一步\n它绝不替你决定 |
| 4 | 9.5–12.5 | 正文里点角色名旁的「＋」→ 档案抽屉打开，露出状态卡（身体/情绪/物品） | 角色有自己的状态\n会累、会记仇 |
| 5 | 12.5–15.5 | 顶部切「全知读者」→ 同一段正文里浮出虚线框的「暗场」 | 主角看不见的暗场\n换个视角全在 |
| 6 | 15.5–19.5 | 设定集卡片墙 → 点一张卡的 ★ → 切「上下文」抽屉，预算表里「常驻卡」亮了 | 四百张设定\n它只取该用的那页 |
| 7 | 19.5–23.0 | 设置 → 连接配置 → 本地模型 → 点「测试连接」，绿字成功 | 本地 9B 跑\n断网也能写 |
| 8 | 23.0–26.0 | 导出对话框 → 选 EPUB → 「打开文件」，资源管理器里出现 .epub | 写完直接导出成书 |
| 9 | 26.0–30.0 | 回到封面静帧，底部出现一行小字 | 开源免费\nGitHub 搜 interactive-novel |

**转场**：2–8 镜之间用「叠化 0.3s」，第 9 镜用「闪白 0.2s」收尾。
**BGM**：抖音搜「国风 空灵 钢琴」或「古琴 悬疑」，40–70 BPM；在第 3、9 镜的重音处各压一次鼓点。
**文字动效**：全部用「淡入 + 上浮 8px」，时长 0.25s，不要花哨的弹跳。

## 2. 横屏 · B 站（90 秒，16:9）

B 站观众愿意看细节，所以按「**从零开始一场故事**」的顺序讲，逻辑链完整。

| # | 时间 | 画面 | 字幕 / 旁白要点 |
|---|---|---|---|
| 1 | 0–5 | `still-16x9` 静帧推近 | （封面字）AI 写小说，但主角是你 |
| 2 | 5–14 | 世界观页 → 新建 → 填「事件背景」（展示 300 字的一段） | 先给它一个世界\n不用写大纲 |
| 3 | 14–24 | 剧本页 → 新建 → 主角名/人设/开场情境 → 进入阅读页 | 你只定义"我是谁" |
| 4 | 24–34 | 第一次生成：流式打字（**原速**，让观众感受 30 tok/s） | 本地模型，原速不加速 |
| 5 | 34–46 | 选项出现 → 选一个 → 新一段；然后**插入行动**自己写一句 | 除了选项，也能自己写 |
| 6 | 46–55 | 档案抽屉：状态卡两层、角色两档 | 世界状态 / 你的状态\n路人 / 重要 |
| 7 | 55–66 | 切全知视角，暗场段落显现（虚线 + 「暗场 ·」） | 主角视角藏起来的部分\n全知视角才给看 |
| 8 | 66–76 | 导演抽屉：写长期大纲 + 本回合指令 → 生成一回合 | 想让它走某条路\n直接下指令 |
| 9 | 76–84 | 存档抽屉 → 读档（回到 3 回合前）→ 正文真的变短 | 后悔了？读档\n设定文档一个字不动 |
| 10 | 84–90 | 上下文抽屉 + 导出 EPUB → 收尾 | 每一次注入了什么\n都能查 · 开源 MIT |

**B 站专属**：进度条章节（投稿时填 10 个时间点）、简介里放 GitHub 链接与"如何自己编译"。
**节奏**：每个操作之间留 0.4s 静止（方便观众看清界面变化），剪辑时再收紧。

## 3. 录制清单（决定成片质量的关键）

| 项 | 建议 | 原因 |
|---|---|---|
| 窗口尺寸 | 横屏 **1600×1000**；竖屏 **900×1560** | 竖屏直接用 16:9 录屏裁切，字会糊成一个点 |
| 显示缩放 | 系统缩放 100%，应用内字号调大两档 | 抖音用户大多在手机上竖屏看 |
| 阅读设置 | 羊皮纸主题、沉浸模式开、行距 1.9、字号 20+ | 画面才有"书"的味道 |
| 侧栏 | 录制前收起，只留正文 | 少一分"软件感"，多一分"小说感" |
| 光标 | 开「单击高亮」（OBS 有内置，剪映也能加） | 手机上看不清鼠标在哪 |
| 帧率/码率 | 60fps，8–12 Mbps，录制 1920×1080 以上 | 文字边缘不糊 |
| 内容 | **另建一个干净的剧本**演示，别用你的真实存档 | 别把私人设定露出去 |
| 素材 | 用 `docs/demo-world/` 里的**原创世界观**演示，别用同人设定集 | 版权风险，且容易被平台判搬运 |

工具：Windows 自带 `Win + G`（Xbox Game Bar，免费够用）；要好一点用 OBS Studio（免费）。

## 4. 片头直接用现成的（已经渲染好了）

把 `intro-vertical-6s.mp4` 拖到时间轴最前面即可——它是「背景缓慢推近 + 文字静止淡入」，比在剪映里手动做关键帧更稳（文字不会跟着缩放糊掉）。

只有想改文案、改节奏时才需要自己重做：

## 4b. 想自己做推近效果

1. 导入 `still-douyin-1080x1920.png` → 拖到时间轴 → 时长设 **3.0s**
2. 选中片段 → 基础设置 → 「缩放」打两个关键帧：**0s 处 100%，3.0s 处 108%**（缓动选"缓入"）
3. 加一层「暗角」滤镜（强度 25%）+「褪色」滤镜（强度 20%），再叠一条黑场淡入 0.4s

这样出来的推近是**从静态图片插值**，不会有 AI 视频常见的画面漂移，也不会糊。

> 想要"活"一点：再加一层「灰尘/颗粒」素材（剪映素材库搜"粒子 尘埃"），混合模式「滤色」，不透明度 15%。

## 6. 合规提醒（别踩）

1. **AI 内容标注**：片子里如果有 AI 生成的画面（本套素材的封面/片头静帧就是），按平台要求勾选「内容由 AI 生成」。纯软件录屏部分不受影响。
2. **别用同人设定集演示**：那是别人的版权作品，容易被判搬运，也会让观众以为软件自带。
3. **别写"全自动写小说"**：容易被判"低质 AI 内容"。你的卖点恰恰相反——**人做决定**，这个反差点一定要讲出来。
4. **别放真实 API Key / 个人路径**：录制前把 `base_url`、文件路径里的用户名抹掉或建一个干净目录。
